# Codex 0.152.0 Termux patch set

## Upstream base

- Tag: `rust-v0.152.0`
- Commit: `316795b3cf2a45e90d121d9f46499d4658b2645c`
- Published target: `termux-v0.152.0`
- Build target: `aarch64-linux-android`

## Termux compatibility retained

1. Browser authentication and update notices use `termux-open-url` and the
   fork-owned release page.
2. The native binary targets `aarch64-linux-android` and resolves the sibling
   `libc++_shared.so` through `$ORIGIN` RUNPATH.
3. Android-specific PTY, clipboard, filesystem-lock, OpenSSL and TLS-root
   compatibility remains target-gated.
4. Runtime update surfaces point only to `pygojrc/codex` releases.
5. The app-server daemon resolves its own executable with `current_exe()`,
   automatic updates remain disabled, and control sockets are owner-only.
6. Android `rusty_v8` 150.4.0 is built from source by the fork-owned workflow
   and consumed through checksum-pinned release assets.
7. The repository publishes only the Termux ARM64 package and its SHA-256
   checksum for this release.
