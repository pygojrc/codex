# Codex 0.146.0 Termux patch set

## Fixed upstream base

- Tag: `rust-v0.146.0`
- Commit: `e363b08c9175ac1cbe5893615dd2cb9ddf95043b`
- Previous audited Termux base: `rust-v0.144.6`

- Build target: `aarch64-linux-android`

## Upstream delta adopted

This release imports the complete OpenAI Codex `0.146.0` source history, including the `0.145.0` interval. The synchronized source includes session naming and pinning, paginated and ephemeral thread forks, Agent Plugins manifests and marketplaces, remote Code Mode WebSocket support, standalone web search for compatible custom providers, expanded proxy routing, MCP refresh fixes, terminal responsiveness improvements and the updated release infrastructure.

Generated protocol schemas, model metadata, dependency versions and `Cargo.lock` use the official `rust-v0.146.0` versions. The official release commit is retained as a Git ancestor.

## Termux compatibility delta retained

1. Browser authentication uses `termux-open-url` on Android.
2. The native binary targets only `aarch64-linux-android` and resolves sibling `libc++_shared.so` through `$ORIGIN` RUNPATH.
3. Android-specific OpenSSL, PTY, clipboard, filesystem-lock and TLS-root compatibility remains target-gated.
4. Runtime update surfaces point only to `pygojrc/codex` releases and never execute a third-party npm updater.
5. The app-server daemon resolves its own executable with `current_exe()`, automatic updates remain disabled and control sockets are owner-only.
6. Code Mode, Guardian and tool routing use the coherent official `rust-v0.146.0` implementation set, including the WebSocket transport and corresponding tests; Termux compatibility remains isolated to the Android-specific layers above.
7. Android `rusty_v8` version `149.2.0` continues to use the checksum-pinned archive and binding pair in `third_party/v8/android-artifacts.toml`.
8. The repository contains only the fork-owned V8 Android, Termux validation and Termux ARM64 release workflows.
9. The release workflow builds with `cargo build --locked`, separates read-only build permissions from release write permissions and publishes a SHA-256 checksum.
